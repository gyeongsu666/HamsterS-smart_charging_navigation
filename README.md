# 🐹 햄스터 로봇 스마트 충전 내비게이션 시스템

학번: 223701 | 이름: 김경수 | 과목: 임베디드 시스템

웹 UI에서 격자 지도를 그리고 배터리 잔량을 설정하면, **다익스트라(Dijkstra)** 알고리즘으로
최적 경로를 계산해 햄스터S 로봇이 자율주행하는 시스템입니다.
목적지까지 배터리가 부족하면 **태양광 충전소를 자동으로 경유**한 뒤 목적지로 이동합니다.

## 하드웨어 연결

| 장치 | 포트 | 비고 |
|------|------|------|
| 햄스터S 블루투스 동글 | COM7 | `HAMSTER_PORT` 상수로 변경 가능 |
| 태양광 자동 추적기 1 | COM6 | `SOLAR_STATION_PORTS[0]` |
| 태양광 자동 추적기 2 | COM8 | `SOLAR_STATION_PORTS[1]` |

> **주의**: 실행 전 Robot Coding 앱과 Arduino IDE 시리얼 모니터를 모두 닫아야 포트 충돌이 없습니다.

## 지도 셀 값

| 값 | 색 | 아이콘 | 의미 |
|----|----|--------|------|
| 0 | 회색 | (없음) | 벽 |
| 1 | 흰색 | (없음) | 길 |
| 2 | 파랑 | 🚗 | 출발지 (지도에 1개만 허용) |
| 3 | 초록 | 🔋 | 태양광 충전소 (복수 배치 가능) |
| 4 | 빨강 | 🏁 | 목적지 (지도에 1개만 허용) |

## 주요 기능

### 1. 경로 탐색 (다익스트라)

- **직행**: 현재 배터리로 목적지까지 이동 가능하면 바로 직행
- **충전소 경유**: 배터리 부족 시, 현재 배터리로 갈 수 있는 충전소 중 완충 후 목적지까지 이어지는 최적 경유지를 자동 선택
  - 경유 순서: 출발지 → 충전소(집게 동작) → 5초 충전 대기 → 목적지

### 2. 충전소 선택 우선순위

| 모드 | 동작 |
|------|------|
| 거리 우선 | 총 이동 거리(출발→충전소 + 충전소→목적지)가 가장 짧은 충전소 |
| 전압 우선 | 도달 가능한 충전소 중 태양광 전압이 가장 높은 충전소 |

> 충전소를 지도에 찍은 순서대로 `SOLAR_STATION_PORTS` 배열의 포트와 1:1 매칭됩니다.
> (첫 번째 찍은 충전소 → COM6, 두 번째 → COM8)

### 3. 실시간 태양광 전압 표시

- 웹 격자의 각 충전소 셀에 전압값(예: `4.2V`)이 1.5초마다 실시간 갱신됩니다.
- 아두이노가 `Serial.println(voltage)` 형식으로 9600 baud 전송 시 자동 수신됩니다.

### 4. 배터리 잔량

| 방식 | 설명 |
|------|------|
| 직접 입력 | 웹 UI에서 % 수동 입력 |
| 로봇에서 불러오기 | `battery_state()` → 3단계(NORMAL=100% / LOW=30% / EMPTY=5%) 자동 환산 |

### 5. 집게 모션

충전소 도착 시 자동으로 집게를 동작합니다.
- `open_gripper()` → 0.5초 대기 → `close_gripper()` → 1초 유지

### 6. 주행 방식

| 모드 | 설명 |
|------|------|
| `board` (권장) | 바닥 검은 라인 + 교차점 센서 인식. 시간 보정 불필요, 오차 없음. |
| `time` | 바퀴를 시간(ms)만큼 굴림. `calibrate.py`로 FORWARD_TIME, TURN_TIME 실측 필요. |

## 주요 상수 (app.py 상단)

```python
ENABLE_HARDWARE     = True      # False 시 시뮬레이션 모드 (로봇 없이 알고리즘만 동작)
HAMSTER_PORT        = "COM7"    # 햄스터S 블루투스 동글 포트
DRIVE_MODE          = "board"   # "board" | "time"
PERCENT_PER_CELL    = 2         # 한 칸 이동 시 배터리 소모량 (%)
SOLAR_STATION_PORTS = ["COM6", "COM8"]  # 충전소별 태양광 추적기 포트 (찍은 순서)
GRIPPER_HOLD_MS     = 1000      # 집게 닫힌 상태 유지 시간 (ms)
```

---

## 시뮬레이션 모드

`ENABLE_HARDWARE = False` 로 설정하면 로봇 없이도 웹 UI와 경로 탐색 알고리즘을
그대로 테스트할 수 있습니다. 주행 명령은 콘솔에 출력됩니다.
